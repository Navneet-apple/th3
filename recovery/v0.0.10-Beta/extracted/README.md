# Th3-Anime v0.0.10-Beta APK recovery

This directory was recovered from the `th3-anime-universal-release-10.apk` GitHub release asset.

## Main app code

- `assets/index.android.bundle` is the original Hermes bytecode bundle from the APK.
- `decompiled.js` is best-effort pseudocode generated from that bundle with `hermes-dec`.
- The rest of the directory contains APK assets and native libraries as packaged by the release.

This is not the original source project. Decompiled output may omit or distort source structure, comments, TypeScript types, names, and control flow. The release did not provide source maps, so those cannot be used to restore the original files.
